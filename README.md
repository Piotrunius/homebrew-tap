# Piotrunius Homebrew Tap

Official Homebrew tap for utilities and tools maintained by [Piotrunius](https://github.com/Piotrunius).

Formulae in this repository are published and updated automatically via CI/CD workflows from their respective source repositories.

## Installation

Install any formula directly:

```bash
brew install Piotrunius/tap/<formula>
```

Or add the tap to your Homebrew installation:

```bash
brew tap Piotrunius/tap
brew install <formula>
```

## Available Formulae

| Formula | Description | Installation |
| :--- | :--- | :--- |
| [`systemupdater`](Formula/systemupdater.rb) | Unified update runner for Linux package managers and dev tools | `brew install Piotrunius/tap/systemupdater` |
